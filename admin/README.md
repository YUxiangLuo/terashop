# Tera Admin

独立的 Svelte 5 / SvelteKit CSR 管理端，与 [Storefront](../storefront/README.md) 共用 Bun workspace、lockfile 和依赖安装。根 layout 关闭 SSR/prerender，adapter-static 输出 SPA fallback。没有服务端路由，也不新增 Edge Function。

## 导航

管理入口分为 Orders（订单、Checkout quotes）、Products（商品、分类）、Inventory（库存、仓库）、Customers、Promotions、Operations（对账异常、支付事件、事件投递 Outbox）及 Settings（配送与运费、税率）。模块名称进入默认页面，旁边的展开按钮只切换二级菜单；同时展开一个模块，深链接及浏览器前进／后退会自动展开当前模块。保留所有原 URL、查询参数和业务页面，不新增概览页。退款／退货／履约仍从订单进入，调拨仍从库存进入。

My Agent connections 位于独立 Personal 区域，非管理员仍仅能进入本人连接页面；导航可见性不替代 RPC 权限检查。650px 及以下使用 Menu 模态抽屉，支持焦点约束、Escape／Close／遮罩关闭，导航成功后关闭；取消离开草稿页则保持原页及抽屉。切回桌面时关闭抽屉并解除滚动锁。

本地验收：`bun scripts/admin-navigation-smoke.ts`。覆盖所有主页面分组及商品深链接、历史返回、桌面和手机布局、键盘焦点、抽屉关闭与屏幕切换、草稿导航取消、降级及退出。截图为 `/tmp/admin-menu-desktop.png`、`/tmp/admin-menu-mobile-closed.png` 和 `/tmp/admin-menu-mobile-open.png`。

## 本地运行

先按根目录 [快速开始](../README.md#快速开始) 安装依赖并初始化可丢弃的本地 Supabase。已有开发环境需要重新 `bun run setup` 才会应用管理员 Storage 策略；这会清空本地数据库。

```bash
bun run admin:dev       # http://127.0.0.1:5174
bun run admin:check     # 不需要数据库
bun run admin:build
bun run admin:preview   # http://127.0.0.1:4175
```

开发/预览只监听回环地址。端口冲突时以终端输出为准。`PUBLIC_SUPABASE_URL` 与 `PUBLIC_SUPABASE_ANON_KEY` 均未设置时自动读取本项目本地服务；远程构建必须同时提供两个公开变量。可用 `bun --env-file=.env scripts/frontend.ts admin build` 读取根环境文件，变量会写入浏览器产物；绝不使用 service-role、S3 secret 或 PayPal secret。

## 第一个管理员

不提供默认密码、自动提升角色或公开管理员注册。对于可丢弃的本地环境：

1. 在本地 Studio `http://127.0.0.1:54323` 的 Authentication 用户管理中创建一个邮箱/密码用户，确认该用户邮箱；只对本地测试账号使用人工确认。
2. 复制该用户的 Auth UUID，在本地 Studio SQL 编辑器执行以下操作（替换占位值）：

```sql
update public.profiles set role = 'admin' where id = '<AUTH_USER_UUID>'::uuid;
```

3. 在 Admin 登录。后续管理员角色管理使用现有 `set_user_role` 合同，不接受客户端 user_metadata 声明的角色。

生产账号必须由受信任运维按身份验证流程创建并授权，不照搬本地人工确认步骤。上线前需要补齐管理员 MFA、密码恢复和相应 Auth 配置。reset 后账号也会消失，需要重新初始化。

## 本人的 MCP 连接

`/connections` 使用本人的 Supabase 会话查询脱敏授权记录，并确认撤销单个、当前页或跨页预览中的明确 ID 集合。这是个人安全页面：非匿名用户即使被降级，也可以访问并撤销自己的连接；其他业务页面仍要求管理员身份。没有管理其他人的授权、创建 token、复制刷新凭据或在线注册 OAuth 客户端的能力。

列表按 UUID 每页 20 条，不是跨页快照。`active` 显示为“Not revoked locally”，不声称连接健康；`cleanup` 分别表示未在此申请清理、待清理、上游清理已确认。撤销成功先停止该授权的新 MCP 准入并删除密文，上游清理由 OAuth 服务异步完成；不能取消已经派发的业务请求。超时保留原 ID 集合，只能重试同一集合；新建的连接不会被旧请求覆盖。页面重载后重新读取事实，不跨标签页持久保存待决操作。Admin 退出不等于撤销 MCP。

“Preview all eligible connections” 单次读取本人所有尚无清理请求的记录，跨越列表分页；含本地已撤销但未请求上游清理的记录。最多 100 条，超过则整体拒绝，须先撤销明确分页再重新预览。预览不撤销、不保存服务端任务。确认区显示完整集合，提交及结果未知后的重试复用同一组 ID，不纳入后来创建的连接；刷新丢弃页面内的预览，不能将旧确认用于新集合。此功能先部署 `20260923000002_mcp_revocation_preview.sql` 再发布 Admin；无需更新授权服务，生产迁移仍须批准。

“My Agent call records” 只读展示本人远程调用摘要，降级后仍可查看；按准入时间及 UUID 倒序，每页 20 条，游标保留微秒，不是快照。刷新回到最新页；读取失败保留旧数据并标记可能过时。四种观察状态不等同于业务结算或交付成功，没有重放按钮；空列表不能证明没有调用。授权删除不会移除历史记录。先部署 `20260923000003_mcp_tool_audit.sql`、`20260923000004_my_mcp_tool_calls.sql`；实际采集仍须运维显式开启 MCP `authorization.auditTools`。不显示参数、结果、凭据或完整授权 binding。浏览器回归覆盖空列表、21 条记录分页、读取失败恢复、本人隔离、降级访问及手机横向滚动；截图为 `/tmp/admin-call-records*.png`。

接入继续由客户端发起 OAuth/PKCE，客户端及回调地址需预注册。可选公开构建变量 `PUBLIC_MCP_CONNECTION` 在页面展示运维提供的 MCP 地址、预期 issuer 和允许申请的业务 scopes；未配置时不推断地址。示例（仅文档占位，须替换为受信部署配置）：

```bash
PUBLIC_MCP_CONNECTION='{"resource":"https://mcp.example.com/mcp","issuer":"https://auth.example.com","scopes":["store:read","store:write"]}' bun run admin:build
```

配置必须且只能包含这三个字段；地址为精确 HTTPS URL，无用户名、密码、query 或 fragment，resource 必须包含非根路径。构建拒绝未知字段、无效地址、重复或未知 scope。只读／日常操作预设仅在所需 scopes 全部允许时展示，不默认申请支付、权限或隐私能力，不改变实际 OAuth 授权。`openid` 和 `offline_access` 等协议 scopes 由预注册客户端及授权服务配置管理，不放入业务预设。这些值会公开打包，不能填写任何 token 或 client secret。更新需重新构建；运维负责与实际服务的 resource、issuer、scopes 和写开关保持一致。

页面不获取远程元数据、不发起授权、不验证公网可用性、不推测授权期限，不实现 SSO、PAT 或健康监控；配置展示不证明当前账号有管理员权限。先应用 `20260923000001_mcp_connection_management.sql`，再更新 OAuth 服务，最后发布 Admin；共享/生产迁移须另行批准。

运行 `bun scripts/admin-connections-smoke.ts`（需本地 Supabase 和运行中的 `bun run admin:dev`）可验证真实登录、本人隔离、已提交回执丢失后的原 ID 重试、新连接不受重试影响、降级后自助撤销及业务门禁。接入信息验证时，服务和脚本使用相同 `PUBLIC_MCP_CONNECTION`，未设置则验证空配置；可用 `ADMIN_URL` 指定其他本地端口。截图保存到 `/tmp/admin-connections*.png` 和 `/tmp/admin-onboarding*.png`；测试使用并清理合成账号与授权，不执行店铺业务写入。真实上游 token 家族清理另由 `tests/mcp-oidc-interaction.test.ts` 的 Node 场景验证。

## 实时失效通知

先部署 `20260923000005_admin_realtime.sql`，确认 Supabase Realtime 可用且反向代理允许 WebSocket，再发布 Admin。该迁移不把业务表加入 `supabase_realtime` publication：数据库事务通过私有 Broadcast 仅发送失效信号（Realtime 自带随机通知 ID），不发送业务行、业务 ID、调用参数或凭据。分类树、分类编辑页和本人的 MCP 调用记录通过现有授权 RPC 重新读取事实；不依赖 MCP 主动通知，因此其他客户端修改也能触发。

分类频道要求管理员，个人调用频道仅允许本人非匿名会话；浏览器没有发布权限。Realtime 的频道权限可能缓存到重连或 JWT 更新，降级后已连接的频道不保证立即停止收到粗粒度通知，**业务权限仍以每次 RPC 校验为准**。个人安全记录降级后仍可查看。

商品列表另需先部署 `20260923000006_admin_product_realtime.sql`。私有 `admin:products` 频道同样要求管理员，仅发送失效通知，覆盖商品、变体、图片和分类关联表。收到通知后按已应用的名称/SKU 和状态条件重读已加载页数，不应用或清空尚未提交的筛选输入；任一页失败保留完整旧列表并提示重试。手动 Refresh products 使用相同规则，Apply 则明确应用新条件并从第一页开始。更新时间排序及非快照分页意味着商品可能跨页移动；不保证视口位置固定。只接入商品列表，商品编辑页、商品分类选择器与库存页仍按原有方式核对，不自动覆盖草稿或待决写入。

通知合并 200ms，隐藏页面不自动读取；重连、回到前台或窗口聚焦会再次核对或提示核对。调用记录仅最新页自动更新，查看旧页时保留当前页并提示手动刷新。分类树每页只建立一个订阅，对根级及已展开分支分别重读已加载的页数；仍在结果中的展开项、URL 筛选和未提交的筛选输入保留，手动 Refresh tree 也不再清空展开状态。某分支任一页失败时保留该分支整批旧结果，提示过时并允许重试，不混用部分新页；分页不是事务快照，新增、移动和删除可能改变页边界与显示顺序。通知不保证可靠送达，不代表操作成功；通知故障不应阻止业务提交，仍可手动刷新。没有持续轮询，也不自动重试业务写入。实际调用记录仍需要启用服务端审计；个人连接列表规则见下方覆盖表。

库存与调拨另需 `20260923000007_admin_inventory_realtime.sql`。管理员私有 `admin:inventory` 频道覆盖库存余额、预占行和新增流水，不广播变体、仓库、报价或订单 ID。库存组件（包括商品详情内的库存区）与调拨页只显示“可能变化”提示，不自动重读或重挂载表单／流水，不覆盖数量、备注、选择、分页或待决请求。Refresh stock 显式核对余额并按原流程刷新流水；新增 Refresh balances 只核对调拨两端余额，保留调拨输入和待决请求，区别于 Reload transfer workspace。读取成功只清除该次读取开始前的通知，读取途中到来的通知继续提示；失败不能解除待决状态。

库存通知是全店粗粒度失效提示，不证明选中库存变化，也不能确认某笔调整／调拨成功。首次订阅、重连和回到前台同样只提示核对。**预占随时间自然到期不一定产生数据库写入，因此没有精确到期推送**；操作前显式刷新，最终数量限制由数据库再次检查。库存商品搜索、商品／仓库选项更新暂未自动接入，需按原方式重新打开或搜索。共享／生产迁移仍需另行批准。

### 当前覆盖与上线边界

补齐剩余页面需依次应用 `20260923000008_admin_domain_realtime.sql`、`20260923000009_mcp_connection_realtime.sql`、`20260923000010_admin_realtime_read_dependencies.sql`。当前全部已有管理路由至少具备其业务域的变化提示，不等于所有页面都会自动刷新：

| 页面 | 处理方式 |
| --- | --- |
| 商品列表、分类树 | 自动重读已加载页数，失败保留整批旧结果 |
| 分类编辑 | 干净时自动重读；草稿、冲突及未知结果保留 |
| 本人调用记录 | 最新页自动重读，历史页仅提示 |
| 本人连接 | 无确认集合时自动重读第一页；后续页、撤销预览和未知撤销保留；创建、撤销、删除及上游清理完成均通知本人 |
| 库存、调拨 | 专属提示，显式核对余额，不推断请求结果 |
| 商品详情、库存商品搜索／选项 | 商品、分类或配置域的页面提示，不自动重建编辑器或选择器 |
| 订单及退款／退货／履约、报价及取消、客户及详情 | 对应业务域的页面提示；退货收货另监听仓库配置；保留草稿、分页、预览与待决请求 |
| 仓库、配送、税率、促销及目标／兑换记录 | 配置域页面提示，不自动重置筛选或编辑 |
| 支付事件、对账、Outbox | 运维域页面提示，仍需显式核对，不把事件或通知当作结算证明 |

通用页面提示挂在授权布局中，只订阅当前路由需要的域，离开路由、退出或权限门禁关闭时清理，不重挂载子页面。同一客户端重新订阅同名频道前等待旧频道退订完成，避免快速 SPA 切换复用正在关闭的频道。首次连接／恢复也会提示核对；Dismiss change reminder 只是收起提示，不代表读取成功，下一次通知会再次显示。提示可能来自同域其他记录，不暴露记录 ID。个人连接频道仅供本人非匿名身份订阅，降级仍能自助撤销；凭据轮换本身不触发连接列表通知。

上线顺序：先在待验收环境备份并经批准应用 `00005`～`00010` 迁移，检查 Realtime 版本支持私有 Broadcast 和 `realtime.send`、WSS 代理与 Auth JWT 配置，再发布 Admin。无需将业务表加入 `supabase_realtime` publication，也无需给浏览器 service key。通过目标环境账号验证普通用户拒绝、跨用户隔离、断线／前台恢复、草稿／未知写保护和上游撤销状态变化；真实 MCP 调用记录另需开启审计。观察数据库通知写入量、Realtime 连接数和 RPC 读取量后再扩大使用，当前本地回归不是生产负载认证。回退旧 Admin 构建不会撤销业务事务；保留通知迁移也不要求旧客户端消费通知。生产迁移、部署、真实域名／TLS 和目标 Agent 验收仍是外部交付门槛，不由本地测试代替。

## MVP 范围

- `/outbox` 提供投递记录只读查询：状态和归属资源 UUID 组合筛选、URL 保留、bigint 字符串游标倒序分页；失败保留已有记录。展开查看可用/租约/发布时间和最近重投审计，累计次数与 retry_start 分别展示，不自行推断耗尽。审计 actor 不是当前租约持有者，published 不证明客户已接收；不展示载荷、原始错误或租约凭据，不提供领取、确认或重投操作。
- `/payment-events` 提供支付 Inbox 只读查询：状态和关联资源 UUID 组合筛选、URL 保留、按创建时间/UUID 倒序分页，原样保留微秒游标；翻页失败保留记录。展示处理次数、后端重试耗尽标记、错误标记、Live/Test 和安全元数据，不展示载荷或原始错误，不提供重放。处理状态不证明收款或对账完成，下一次尝试时间不是处理承诺。
- Inbox 的资源 ID 是意图、交易、退款请求或渠道资金记录，不是订单或事件 ID；无资源筛选才包含未关联事件。对账记录提供按资金记录 ID 查询事件的入口，但资源关联不保证包含其来源事件，不提供精确事件 ID 搜索。切换资源清空状态和游标；无跨页快照。
- `/reconciliation` 查询全店未解决的渠道资金变动，包括没有关联订单的记录。分别查询 unmatched / action_required，URL 保留筛选，按创建时间及 UUID 最早优先分页，微秒游标原样传递；下一页失败保留已加载记录。金额按原币种及原始十进制字符串显示，不换算、舍入或跨币种合计。
- 对账页仅展示安全引用 ID、错误标记和关联订单入口，不显示渠道引用、原始错误或载荷。记录不等于已结算账本资金，空页不证明系统健康，错误标记不是重试许可，无跨页快照。不提供自动匹配、资金重放或退款；action_required 交由受信运维核查。
- `/quotes` 提供只读 Checkout 报价查询，支持客户 UUID、有效状态、是否关联订单组合筛选，URL 保留筛选条件，按 UUID 游标分页；下一页失败保留已有记录并可重试。详情显示历史价格、地址、备注及客户/订单链接，支持直接打开和刷新。
- 报价有效状态与存储状态分别显示；预留标记不是库存数量或付款证明，显示过期不证明后台已完成释放，须重新读取获取当前事实。不提供延期或独立释放库存操作，无跨页快照，不添加兼容接口或数据转换。
- 从报价详情进入独立取消页，填写客户可见原因（非空白、最多 500 个 Unicode 码点，与 MCP 一致；不是 UTF-16 长度）并确认。取消 converted 报价同时取消关联未付款订单，释放预占和优惠用量，不退款、不恢复已发货库存；付款或履约状态及捕获中保护由后端检查。按管理员/报价在当前标签页保存原请求，结果未知时仅重试原原因；重读存储终态确认取消或提示已过期/已完成，不把有效过期当作取消成功，不推断操作者，保留后端实际原因。读取失败锁定操作，关闭标签页不保留恢复记录。
- 邮箱密码登录、会话恢复、退出；不同于 Storefront 的独立会话存储 key。通过 `is_admin()` 验证数据库角色后才挂载管理页面，后端仍独立验证每个 RPC/Storage 请求。刷新 token、窗口重新聚焦时重新检查权限。

- 未保存字段只在内存中，离开页面会提示；退出或丢失会话会清除编辑界面。不要把浏览器提示当作持久草稿。创建时先保存商品，再上传图片。

P2：已有发货记录可更新承运商、单号、跟踪链接，已发货记录可确认送达或取消。使用原 version 和持久化幂等键；未知结果只重试原请求，版本冲突须重新读取。取消发货不退款、不回库，不能修改商品或数量。

`/customers` 支持姓名/邮箱/电话搜索、匿名化筛选与游标分页。详情可修改联系方式、查看只读地址和关联订单；匿名化记录只读。更新原样携带 `updated_at`，冲突或结果未知须显式重读。联系方式修改不改变登录账号或历史订单快照；本批不提供客户新建、匿名化、地址写入。

完整 RPC 参数和错误语义见 [API](../docs/api.md#原子商品编辑)。草稿不会出现在公开 API；发布后需重新构建 Storefront SSG 才能更新静态页面。保存不会自动触发远程构建或部署。

### 库存与发货的失败恢复

库存调整、发货创建和发货更新命令先在 `sessionStorage` 保存完整参数及幂等键，按管理员 UUID、操作类型与商品/订单/发货记录隔离；存储失败不发送请求。未知结果保留原请求、锁定新操作，刷新页面后仍可显式重试同一请求，不自动重试或换键。首次明确数据库拒绝允许修正；已未知请求的重试被拒绝不证明原操作失败，仍保留原请求。成功回执通过归属检查后才清除。

操作记录包含库存备注或物流信息，不含 Auth token、客户地址；退出不清除未决记录，供同一管理员恢复。**只保证当前标签页的恢复，不是服务端任务队列或跨标签页去重。** 关闭标签页、清除浏览器数据或换设备后，必须先核对后台事实，不能重新创建同一操作。长期无法恢复的请求需受信运维核查，不直接删记录盲重试。界面显示的库存或发货记录不是外部物流/资金到账证明。

## 图片权限与失败处理

Admin 新上传复用 MCP 的 `managed-media` Edge Function：**私有暂存 → 明确确认永久公开 → 加入表单 → 保存商品关联**。JPEG/PNG/WebP，非空且最多 **1 MiB**（与 managed-media 服务上限一致）；先保存商品再上传，一次处理一张。发布不会自动修改商品。

浏览器使用管理员自己的 Auth 会话，不分发 service role key。部署前单独设置服务端 `MEDIA_ALLOWED_ORIGINS`，逗号分隔、精确匹配 Admin origin（生产 HTTPS）；默认空列表拒绝浏览器访问，**不继承 `PAYMENT_ALLOWED_ORIGINS`**，无 Origin 的 MCP 调用不受影响。CORS 不代替 Auth 和数据库 admin 角色校验。允许的 origin 在错误响应中也有 CORS header，便于客户端保留失败状态。

本地示例（只含这一项的服务端环境文件；不要把混合 `.env.example` 当生产 secrets 全量上传）：

```sh
printf 'MEDIA_ALLOWED_ORIGINS=http://127.0.0.1:5174\n' > /tmp/tera-media.env
bunx --no-install supabase functions serve managed-media --env-file /tmp/tera-media.env
```

上传前，按管理员和商品隔离的 `sessionStorage` 保存 request UUID、MIME、字节数和 SHA-256，不保存文件内容或 token。丢失回执后先按 request UUID 查询事实；仅同一文件可以显式重试原请求，不生成新 UUID、不自动重写 Storage。已写入但回执丢失的字节通过恢复操作核验，不能核验时交由受信运维调查。当前标签页刷新可恢复；关闭标签页或清除浏览器数据会丢失记录，应保留 request UUID 供 MCP 查询。

私有暂存不向浏览器提供预览或 signed URL。点击发布需要明确确认；发布前永久保留，公开对象为 `catalog-media/managed/<media UUID>.jpg|png|webp`，包括草稿商品在内，任何持有 URL 的人均可读取。**一旦发布，Admin/MCP 均不允许删除或转回私有**。发布成功后需加入表单并保存商品，读取确认关联后才清除本地恢复记录；发布和商品保存不在一个事务中。放弃未公开素材的 discard/delete 流程仍由 MCP 执行，Admin 可核对并结束已确认删除的记录，不做自动垃圾回收。

旧 `products/<product UUID>/<image UUID>.<ext>` 公开文件、外部 URL 和既有 Storage RLS 保持兼容，不迁移、不假装可以撤回公开。移除图片仅在保存后移除关联，保留字节。底层旧 bucket 的 5 MiB 配置不等于新上传服务上限；MIME/扩展名限制也不等于内容检测或重新编码。

本地浏览器回归：`bun scripts/admin-media-smoke.ts`，以临时 loopback HTTP 服务运行真实 Edge handler，连接真实本地 Auth/DB/Storage，并注入丢失回执；不代替实际部署的 Edge 网关验收。

## 静态部署与验收

location / {
