# Admin / MCP 联合交付记录

本页保留 A—D 批次的交付范围，不作为当前操作手册或实时测试报告。当前能力见 [Admin](../admin/README.md) 和 [MCP](../mcp/README.md)，运行验收见 [测试指南](testing.md)，部署顺序见 [MCP 运维](../mcp/OPERATIONS.md)。

## 已完成的本地范围

| 批次 | 交付内容 |
| --- | --- |
| A：合同 | 共享 scope/金额/税率输入合同，核对工具权限与路由映射，推荐 managed-media 路径 |
| B：人工接管 | 客户创建/地址、商品高级字段、促销目标搜索、素材恢复/私有删除、停用仓库历史、资源导航 |
| C：高风险协作 | 绑定身份/参数/状态/有效期的逐笔审批，调用观察关联业务资源，未知结果查询与人工恢复 |
| D：验收 | 类型/单元/数据库/构建/SQL lint/类型漂移检查，桌面/手机与异常状态浏览器回归，Realtime 边界说明 |

目标是让人能核对、接管和恢复 Agent 操作，不要求每个工具都有独立页面，也不建设覆盖所有 CRUD 的通用任务系统。
